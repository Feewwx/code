# 1. 绪论

## 1.1. 数据结构的研究内容

```
                                             |-分析问题-|
                                             |
                    |-具体问题抽象为数学模型-|-提取操作对象-|
                    |                        |
                    |                        |-找出操作对象之间的关系-|
                    |                        |
                    |                        |-用数学语言描述-| => 数据结构
怎么用编程解决问题:-|
                    |-设计算法-|
                    |
                    |-编程,调试,运行-|
```

`"程序 = 数据结构 + 算法"`

大家都知道编程中有很多非数值计算问题的数学模型,有很多诸如表,树,图之类的具有逻辑关系的数据

**数据结构**就是一门研究非数值计算的程序设计中计算机的操作对象以及它们之间的关系和操作的学科

## 1.2. 基本概念和术语

### 1.2.1. 数据,数据元素,数据项和数据对象

#### 1.2.1.1. 数据

**数据**是能输入计算机且能被计算机处理的各种符号的集合

- 数据:
    - 信息的载体
    - 对客观事物符号化的表示
    - 能够被计算机识别,存储并加工

- 分为:
    - 数值型的数据:整数,实数等
    - 非数值型的数据:文字,图像,图形,声音等

#### 1.2.1.2. 数据元素

**数据元素**是数据的基本单位,在计算机程序中通常作为一个整体进行考虑和处理

- 也简称为元素,或称为记录,结点或顶点

#### 1.2.1.3. 数据项

**数据项**是构成数据元素的不可分割的最小单位

数据 > 数据元素 > 数据项

> 例: 学生表 > 个人记录 > 学号,姓名...

#### 1.2.1.4. 数据对象

**数据对象**是性质相同的数据元素的集合,是数据的一个子集

> 数据元素和数据对象的区别:

**数据元素**--组成数据的基本单位

- 与数据的关系:集合的个体

**数据对象**--性质相同的数据元素的集合

- 与数据的关系:集合的子集

数据项 ⊂ 数据元素 ⊂ 数据对象 ⊂ 数据

例: 数据对象:全校所有学生记录 - 性质相同的数据元素的集合

### 1.2.2. 数据结构

数据元素不是孤立存在的,它们之间存在着某种关系,数据元素相互之间的关系称为结构

所以**数据结构**是指相互之间存在一种或多种特定关系的数据元素集合,或者说是带结构的数据元素的集合

数据结构包含以下三个方面的内容:

- 数据元素之间的逻辑关系,也称为逻辑结构
- 数据元素及其关系在计算机内存中的表示(又称为映像),称为数据的物理结构或数据的存储结构
- 数据的运算和实现,即对数据元素可以施加的操作以及这些操作在相应的存储结构上的实现
