#####
线性表的顺序表示又称为顺序存储结构或顺序映像

顺序存储定义:把逻辑上相邻的数据元素存储在物理上相邻的存储单元中的存储结构

> 线性表:(a1, a2, ..., ai-1, ai, ai+1, ..., an) 

简言之,就是逻辑上相邻,物理上也相邻

线性表的第一个数据元素a1的存储位置,称作线性表的起始位置或基地址

例:

- [1][2][3][4][5][6]
    - 依次存储,地址连续--中间没有空出存储单元
    - 所以,这是一个典型的线性表顺序存储结构

- [1][2][ ][ ][3][4][5][6]
    - 地址不连续--中间存在空的存储单元
    - 所以这不是一个线性表顺序存储结构

- 线性表顺序存储结构占用一片连续的存储空间,知道某个元素的存储位置就可以计算其他元素的存储位置
    - 假设线性表的每个元素需占l个存储单元,则第i+1个数据元素的存储位置和第i个数据元素的存储位置之间满足关系:
    - LOC(ai+1) = LOC(ai) + l
    - 因此,所有数据元素的存储位置均可由第一个数据元素的存储位置得到:
    - LOC(ai) = LOC(a1) + (i-1)*l

顺序表(元素) -> 地址连续,依次存放,随机存取,类型相同 -> 数组 -> 用一维数组表示顺序表

线性表长可变(删除),数组长度不可动态定义 -> 用一变量表示顺序表的长度属性

- 通讯录
    - 查找
        - 平均查找长度ASL(Average Search Length):
            - 为确定记录在表中的位置,需要与给定值进行比较的关键字的个数的期望值叫作查找算法的平均查找长度
            - ASL = Σ(Pi × Ci)
            - 等概率平均 → (1+2+…+n)/n = (n+1)/2
    - 插入
        - 插入位置共有 n+1 种可能(第 1 个元素之前,任意两个元素之间,最后一个元素之后),假设每种概率相同,都是 1/(n+1)
        - 插在第 i 个位置时,原来第 i 个到第 n 个元素都要后移一格,移动次数是 n - i + 1
            - 插在最前面(i=1):移动 n 次
            - 插在最后面(i=n+1):移动 0 次
        - 平均移动次数:
            - E(ins) = 1/(n+1) × Σ(i=1→n+1)(n - i + 1) = 1/(n+1) × (n + ... + 1 + 0) = 1/(n+1) × n(n+1)/2 = n/2
        - 平均要移动一半的元素,n/2 与 n 同数量级,所以顺序表插入算法的平均时间复杂度为 O(n)
    - 删除
        - 删除位置共有 n 种可能,假设每种概率相同,都是 1/n
        - 删除第 i 个位置时,原来第 i+1 个到第 n 个元素都要前移一格,移动次数是 n - i
            - 删最前面(i=1):移动 n-1 次
            - 删最后面(i=n):移动 0 次
        - 平均移动次数:
            - E(del) = 1/n × Σ(i=1→n)(n - i) = 1/n × ((n-1) + ... + 1 + 0) = 1/n × (n-1)n/2 = (n-1)/2
        - 平均要移动近一半的元素,(n-1)/2 与 n 同数量级,所以顺序表删除算法的平均时间复杂度为 O(n)

- 顺序表的优缺点
    - 优点:
        - 存储密度大(结点本身所占存储量/结点结果所占存储量)
        - 可以随机存取表中任一元素
    - 缺点:
        - 在插入,删除某一元素时,需要移动大量元素
        - 浪费存储空间
        - 属于静态存储形式,数据元素的个数不能自由扩充
