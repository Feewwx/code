> 统计'\0'前面出现的字符个数

- 如果字符串里没有'\0',就一直往后面找,什么时候找到\0什么时候停止并输出

> 模拟实现

```c
#include <stdio.h>
#include <assert.h>

size_t my_strlen(const char *str) {
    size_t count = 0;
    assert(str);
    while (*str != '\0') {
        count++;
        str++;
    }
    return count;
}

int main() {
    char arr[] = "hello";
    size_t n = my_strlen(arr);
    printf("%zu\n", n);
    return 0;
}
```
