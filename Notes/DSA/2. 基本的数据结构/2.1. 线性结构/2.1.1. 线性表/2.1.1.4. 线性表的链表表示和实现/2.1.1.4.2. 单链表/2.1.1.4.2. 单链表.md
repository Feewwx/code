- 带头结点的单链表
    - 单链表由表头唯一确定,因此单链表可以用头指针的名字来命名,若头指针名为L,则把链表称为表L
    - 为了统一链表的操作,通常这样定义:
    - 元素类型定义:

    ```c
    typedef struct {
        char num[8];    //数据域
        char name[8];   //数据域
        int score;      //数据域
    } ElemType;
    ```

    - 结点类型定义:

    ```c
    typedef struct Lnode{       //声明结点的类型和指向结点的指针类型
        ElemType    data;       //结点的数据域
        struct Lnode *next;     //结点的指针域
    }Lnode, *LinkList;          //LinkList为指向结构体Lnode的指针类型
    ```

- 单链表的初始化
    - 即构造一个空表

```c
Status InitList_L(LinkList &L){
    L = new LNode;  //或L= (LinkList) malloc ( sizeof (LNode));
    L->next=NULL;
    return OK;
}
```

- 重要操作:

```c
p = L;  // p指向头结点
s = L -> next;  // s指向首元结点
p = p -> next;  // p指向下一结点
```

- 补充单链表的几个常用简单算法
    - 判断链表是否为空:
        - 空表:链表中无元素,称为空链表(头指针和头结点仍然在)
        - 算法思路:判断头结点指针域是否为空

        ```c
        int ListEmpty(LinkList L){   //若L为空表,则返回1,否则返回0
            if(L->next)  //非空
                return 0;
            else
                return 1;
        }
        ```
    - 单链表的销毁:链表销毁后不存在
        - 算法思路:从头结点开始,依次释放所有结点

        ```c
        Status DestroyList_L(LinkList &L){  //销毁单链表L
            Lnode *p;  //或LinkList p;
            while(L) {
                p=L;
                L=L->next;
                delete p;
            }
            return OK;
        }
        ```
    - 清空链表:链表仍存在,但链表中无元素,成为空链表(头指针和头结点仍然在)
        - 算法思路:依次释放所有结点,并将头结点指针域设置为空
        - 循环条件 `p!=NULL`,结束条件 `p==NULL`;最后头结点指针域置空

        ```c
        Status ClearList(LinkList &L){      //将L重置为空表
            Lnode *p, *q;                   //或LinkList p,q;
            p = L->next;
            while(p) {                      //没到表尾
                q = p->next;
                delete p;
                p = q;
            }
            L->next = NULL;                 //头结点指针域为空
            return OK;
        }
        ```

        - 和销毁的区别:清空保留头指针和头结点,销毁会把头结点也一起释放

    - 求单链表的表长:返回L中数据元素个数
        - 算法思路:从首元结点开始,依次计数所有结点
        - 表长不含头结点,所以从 `L->next` 开始数

        ```c
        int ListLength_L(LinkList L){       //返回L中数据元素个数
            LinkList p;
            int i = 0;                      //计数器
            p = L->next;                    //p指向第一个结点
            while(p) {                      //遍历单链表,统计结点数
                i++;
                p = p->next;
            }
            return i;
        }
        ```

    - 取值:取单链表中第i个元素的内容
        - 算法思路:从链表的头指针出发,顺着链域next逐个结点往下搜索,直至搜索到第i个结点为止;因此,链表不是随机存取结构
        - `if(!p || j>i)`: `!p` 是表长不够,`j>i` 说明 i<1;两种情况都是第 i 个元素不存在

        ```c
        Status GetElem_L(LinkList L, int i, ElemType &e){  //获取线性表L中的某个数据元素的内容,通过变量e返回
            LinkList p;
            int j;
            p = L->next; j = 1;                            //初始化
            while(p && j < i) {                            //向后扫描,直到p指向第i个元素或p为空
                p = p->next; ++j;
            }
            if(!p || j > i) return ERROR;                  //第i个元素不存在
            e = p->data;                                   //取第i个元素
            return OK;
        }  // GetElem_L
        ```

    - 查找:
        - 按值查找(返回地址):根据指定数据获取该数据所在的位置(该数据的地址)
            - 算法思路:从首元结点开始,顺着 next 找第一个 data == e 的结点
            - 找到返回结点地址;找不到就走到 NULL,正好拿 NULL 当失败标志

            ```c
            Lnode *LocateElem_L(LinkList L, ElemType e) {  //在线性表L中查找值为e的数据元素
                LinkList p = L->next;
                while(p && p->data != e)                   //没到头且值不等就往后走
                    p = p->next;
                return p;                                  //找到返回地址,失败返回NULL
            }
            ```

        - 按值查找(返回位序):根据指定数据获取该数据所在的位置序号(是第几个数据元素)
            - 算法思路:同上,多一个 j 记位置
            - 找到返回 j(位序从1开始);失败返回 0,因为 0 是非法位序,正好当错误标志

            ```c
            int LocateElem_L(LinkList L, ElemType e) {     //返回值为e的数据元素的位置序号
                LinkList p = L->next;
                int j = 1;
                while(p && p->data != e) {
                    p = p->next;
                    j++;
                }
                if(p) return j;                            //找到了
                else return 0;                             //没找到
            }
            ```

    - 插入:在第i个结点前插入值为e的新节点
        - 算法思路:p 先走到第 i-1 个结点(前驱),因为单链表只能改前驱的 next
        - 头结点让 i=1 也统一:p=L, j=0;循环停在 j==i-1
        - 非法条件:`!p` 就是 i>表长+1,`j>i-1` 就是 i<1;两种都返回 ERROR
        - 找到前驱是 O(n),真正插入只要 O(1)

        ```c
        Status ListInsert_L(LinkList &L, int i, ElemType e) {  //在L中第i个元素之前插入数据元素e
            LinkList p = L;
            int j = 0;
            Lnode *s;
            while(p && j < i-1) { p = p->next; ++j; }          //找第i-1个结点,p指向前驱
            if(!p || j > i-1) return ERROR;                    //i>表长+1 或 i<1,位置非法
            s = new Lnode; s->data = e;                        //生成新结点s,数据域置e
            s->next = p->next;                                 //先接s的后继
            p->next = s;                                       //再让前驱指向s
            return OK;
        }  // ListInsert_L
        ```

        - 两句顺序不能反:先 `s->next=p->next` 再 `p->next=s`;反了 p->next 被覆盖,后面整条链就丢了

    - 删除:删除第i个结点
        - 算法思路:p 走到第 i-1 个(前驱),q 抓住第 i 个,改前驱的 next 跳过 q,再释放 q
        - 循环条件跟插入不一样:是 `p->next && j<i-1` 不是 `p` —— 要删的结点本身必须存在,所以看的是前驱有没有后继
        - 非法条件:`!(p->next)` 就是 i>表长,`j>i-1` 就是 i<1
        - 顺序不能反:先 `p->next=q->next` 断链,再 `delete q`;反了 q->next 跟内存一起没了,后面整条链接不上
        - `e=q->data` 必须在 delete 之前取;先把值带回去,再放内存
        - 找位置 O(n),真正删除 O(1)

        ```c
        Status ListDelete_L(LinkList &L, int i, ElemType &e) {  //在L中删除第i个元素,用e带回被删的值
            LinkList p = L;
            int j = 0;
            Lnode *q;
            while(p->next && j < i-1) { p = p->next; ++j; }     //p 找第 i-1 个结点(前驱)
            if(!(p->next) || j > i-1) return ERROR;             //i>表长 或 i<1,位置非法
            q = p->next;                                        //q抓住要删的结点
            p->next = q->next;                                  //前驱跨过q
            e = q->data;                                        //先保存值
            delete q;                                           //再释放空间
            return OK;
        }  // ListDelete_L
        ```
    
    - 单链表的建立
        - 头插法:元素插入在链表头部,也叫前插法
            - 算法思路:每 new 一个结点,把它的 next 指向当前首元结点,再让头结点指向它,新结点就挤到最前面
            - 建表前先 `L = new LNode; L->next = NULL;`,搭一个带头结点的空表
            - 输进去的顺序和链表里的顺序是反的:循环从 i=n 降到 1,最后输入的反倒排最前面
            - 两句顺序不能反:先 `p->next = L->next` 再 `L->next = p`;反了 p->next 被覆盖,原来那串结点就找不回来了
            - 每个结点 O(1) 插到表头,建整表 O(n)

            ```c
            void CreateList_H(LinkList &L, int n) {   //逆位序输入 n 个元素的值,建立带头结点的单链表L
                L = new LNode;
                L->next = NULL;                       //先建立一个带头结点的空表
                for(i = n; i > 0; --i) {
                    p = new LNode;                    //生成新结点
                    cin >> p->data;                   //输入元素值
                    p->next = L->next;                //插入到表头
                    L->next = p;
                }
            }  // CreateList_H
            ```
        - 尾插法
            - 算法思路:头插法每次挤到表头,读入顺序和链表顺序相反;尾插法每次接在表尾,读入顺序就是链表顺序
            - 要额外维护一个尾指针 r 指向尾结点,不然每插一个都要从头走到尾,建整表就是 O(n^2)
            - 初始时 r = L(指向头结点,不是首元结点),这样第一次插入和后面每次走同一套逻辑,不用特判空表
            - 新结点先 p->next = NULL:它是新的尾结点,后面不会再有人接它
            - 两句顺序不能反:先 r->next = p 接上,再 r = p 让尾指针跟过去;反了 r 已经跑到 p,r->next = p 就成了自己指自己
            - 每个结点 O(1) 接到尾部,建整表 O(n)

            ```c
            void CreateList_R(LinkList &L, int n) {   //正位序输入 n 个元素的值,建立带头结点的单链表L
                L = new LNode;
                L->next = NULL;                       //先建立一个带头结点的空表
                r = L;                                //尾指针 r 指向头结点
                for(i = 0; i < n; ++i) {
                    p = new LNode;                    //生成新结点
                    cin >> p->data;                   //输入元素值
                    p->next = NULL;                   //新结点就是新的尾结点
                    r->next = p;                      //接到表尾
                    r = p;                            //尾指针后移
                }
            }  // CreateList_R
            ```
