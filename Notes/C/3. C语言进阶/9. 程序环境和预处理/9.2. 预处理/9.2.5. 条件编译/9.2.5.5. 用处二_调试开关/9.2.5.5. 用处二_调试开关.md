```c
#ifndef DEBUG
#define DEBUG 1
#endif

int main(void) {
#if DEBUG
    printf("DEBUG: x=%d\n", 42);
#endif
    printf("正常输出\n");
    return 0;
}
```

```bash
gcc -o t   t.c              # DEBUG=1,带调试输出
gcc -DDEBUG=0 -o t t.c      # 关掉
```

关掉之后那段代码**连编译出来的二进制文件里都搜不到**(用 `strings t` 找不到).不是运行时跳过 - 它压根没进过编译器,所以不占空间也不占运行时间.
